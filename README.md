# Get It Done List

Deployment URL: https://a4-jacobcamoin.onrender.com

Get It Done List is a task manager to organizes tasks for the week - sorting by priority and automatically calculates deadlines. It uses local login/signup, GitHub OAuth, MongoDB storage. Users can add, edit, and delete
I used React to re-implemented the A3 assignment. Spliting the task form, task list, task rows, login page, and dashboard into components and used React state. React made editing and refreshing the task list easier to manage, although it required an extra build step.
